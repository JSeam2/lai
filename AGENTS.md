# AGENTS.md

## Repository Expectations
- Work using test driven development. Write tests cases before we start implementing features.
- Ensure that code remains understandable and formatted in a way that is readable for a human developer.
- Keep things short and simple.
- Do not repeat yourself, ensure code is not reused.
- Utilize known design patterns instead of reinventing things when possible.

## Acceptance Criteria
- Ensure that `cargo clippy` runs without failures
- Ensure that `cargo nextest run` runs without failures
